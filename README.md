# Natalie's Shop 

### Project Overview
A responsive e-commerce website built with React.js, featuring login with user, product browsing , product details, category-based navigation, and a shopping cart and chekout experience. The project uses external APIs to fetch and display product data dynamically, with a clean and responsive user interface.


### Live Demo
[View the Website](https://e-commercenat.vercel.app/)
### Video Preview
[Watch the Website Demo](https://youtu.be/0gu01kG6_ds)


## Key Features

- Browse products
- Browse products by category
- View product details
- Add products to the shopping cart
- Increase or decrease product quantities
- Remove products from the cart
- Calculate cart totals
- Responsive design
- Fetch product data from APIs
  

## Technologies Used
`React.js` `Vite` `JavaScript` `React Router` `Axios` `Bootstrap` `React Bootstrap` `React Helmet` `React Spinners` `SweetAlert` `Typewriter Effect` `REST API` `Git & GitHub` `Vercel`
#### API
Product data is fetched dynamically from both the [Fake Store API](https://fakestoreapi.com/) and [DummyJSON](https://dummyjson.com/).

## Installation
1. Clone the repository
```bash
git clone https://github.com/Natalie31706-code/e-commercenat.git
```

2. Navigate to the project folder
```bash
cd e-commercenat
```

3. Install dependencies
```bash
npm install
```

4. Run the development server
```bash
npm run dev
```
The project will be available at the local development URL provided by Vite.

## Project Purpose
This project was built to practice React development, API integration, routing, reusable components, state management, and responsive web design while creating a functional e-commerce website.
